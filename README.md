# VRCNext Example Plugin

A working VRCNext plugin that uses every capability the host provides, one per file — the template to start a plugin from.

**Documentation:** <https://vrcnext-plugins.github.io/plugin-example.html> · writing plugins: <https://vrcnext-plugins.github.io/getting-started.html>

```bash
npm install && npm run check
```
